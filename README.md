## About the Project

This portfolio was built as both a professional branding platform and an ongoing AI-assisted development project.

It showcases my background, projects, certifications, creative work, technical skills, services, achievements, and learning journey across:

- Data Science
- Data Analytics
- Artificial Intelligence
- Creative Design
- Digital Education
- Technical Communication
- AI-Assisted Workflows

Rather than manually building every part from scratch, I used AI-assisted workflows throughout the development process while directing the overall structure, design decisions, content organization, feature planning, debugging, responsiveness, and visual refinement myself.

The project reflects a modern human-AI collaborative workflow where AI acts as a development and productivity partner, while I guide the creative, technical, and strategic direction.

## Current Portfolio Structure

The portfolio now uses a cleaner project hub structure.

Instead of loading every design directly on the homepage, the homepage highlights major project categories and links to dedicated project pages.

### Main Pages

- `index.html` — main portfolio homepage
- `gallery.html` — CodeDevPay campaign gallery
- `ads.html` — campaigns and advertisements gallery
- `tshirts.html` — T-shirt and apparel design gallery

This improves loading speed, keeps the homepage cleaner, and makes the project section easier to expand over time.
